# MailManager

Página informativa de MailManager para Windows, con política de privacidad y términos de uso.

Preparada para GitHub Pages en `carloslemus28.github.io`.

## Publicación

En Settings → Pages selecciona Deploy from a branch, la rama `main` y la carpeta `/(root)`. GitHub debe confirmar el despliegue antes de considerar publicadas estas direcciones:

- https://carloslemus28.github.io/
- https://carloslemus28.github.io/privacidad.html
- https://carloslemus28.github.io/terminos.html

El sitio es HTML, CSS y JavaScript estático. No requiere instalar dependencias, ejecutar un servidor propio ni configurar una base de datos. La carpeta `assets` contiene los logotipos de MailManager. `.nojekyll` permite servir los archivos estáticos sin transformar su contenido con Jekyll.

Contacto público autorizado: celemuszelidon@gmail.com.

Esta web no contiene el ejecutable de escritorio, credenciales OAuth, tokens, perfiles de Windows ni correos reales. La bandeja de la portada es una ilustración con datos de ejemplo.

La publicación no constituye una aprobación de Google. Una vez disponible el sitio, debe verificarse su propiedad en Google Search Console y configurarse la marca y el acceso a datos del proyecto OAuth correspondiente.
